# GNOME keyboard shortcuts

Default GNOME/Ubuntu bindings. Check/customize under
**Settings > Keyboard > Keyboard Shortcuts** — exact defaults can shift
slightly between GNOME versions.

## Windows

| Shortcut | Action |
|----------|--------|
| `Alt+Tab` | Switch between open windows |
| `Alt+Shift+Tab` | Switch windows, reverse direction |
| `` Alt+` `` | Switch between windows of the same app |
| `Alt+F4` | Close window |
| `Super+Up` | Maximize window |
| `Super+Down` | Restore / minimize window |
| `Super+H` | Minimize window |
| `Super+Left` | Tile window to the left half |
| `Super+Right` | Tile window to the right half |
| `Alt+F7` | Move window (then arrow keys or mouse) |
| `Alt+F8` | Resize window |

## Workspaces

| Shortcut | Action |
|----------|--------|
| `Super+Page Up` | Switch to the workspace above |
| `Super+Page Down` | Switch to the workspace below |
| `Ctrl+Alt+Up` | Switch to the workspace above (alt binding) |
| `Ctrl+Alt+Down` | Switch to the workspace below (alt binding) |
| `Super+Shift+Page Up` | Move current window to the workspace above |
| `Super+Shift+Page Down` | Move current window to the workspace below |

## Programs / general

| Shortcut | Action |
|----------|--------|
| `Super` | Open the Activities overview |
| `Super+A` | Show all applications |
| `Super+Tab` | Switch between applications |
| `Ctrl+Alt+T` | Open a terminal (Ubuntu default) |
| `Super+L` | Lock screen |
| `Super+V` | Show the notification list |
| `PrtScn` | Screenshot (full screen) |
| `Shift+PrtScn` | Screenshot (select an area) |
| `Alt+PrtScn` | Screenshot (active window) |
